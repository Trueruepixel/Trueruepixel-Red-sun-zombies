# Red Sun Zombie Assault

A mobile browser game featuring Argentum, Forgotten, Patches, Ken, and boss Preem.

## Upload to GitHub

1. Create a new public repository named `red-sun-zombie-assault`.
2. Extract this ZIP.
3. Upload **all files and the entire `assets` folder** to the repository.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.

Your game link will be:

`https://YOUR-USERNAME.github.io/red-sun-zombie-assault/`

Do not upload only `index.html`. The `assets` folder contains the pictures and music.
